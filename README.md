# 🧑‍🔬 Lab Hero: Biosafety Blitz

A ~3-minute interactive browser game that teaches core biosafety rules.
Single file (`index.html`), no dependencies, no network calls: works on any device and any network, even offline.

**Rounds:** 1) PPE catch · 2) Waste sorting · 3) Spill drill · 4) Hazard hunt · 5) BSL match

**Play:** open `index.html`, or enable GitHub Pages (Settings → Pages → Deploy from branch → `/ (root)`) for a public link.
